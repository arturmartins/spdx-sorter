## Critical Anti-Patterns (do NOT repeat these)

- Do not install Hatchling into `/opt/venv`; `/opt/build-venv` owns all build
  tooling and only the runtime environment is copied into the final image.
- Do not treat an attestation action alone as proof of SLSA Build Level 3. The
  reusable workflow design and successful exact-signer verification are needed.
- Do not publish, create tags/releases, mutate remote settings, or use registry
  credentials while implementing repository files.
- Do not let pull-request workflows receive OIDC, attestations, package-write,
  or protected environment access.
